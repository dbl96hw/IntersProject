## GenDD Context Pack

This repo is configured for GenDD. Before planning or changing code, load the context below.

- `gendd/` - plugin configuration and generated documents: `config.md` (tracker, test commands,
  coverage threshold, security severity bar), `definition-of-ready.md`, `definition-of-done.md`,
  `tickets/` (local mirror of the Trello board), `adr/` (Architecture Decision Records), `specs/`
  (including `uc4-use-case.md`, the hackathon use case, and `feature-roadmap.md`, the phased feature
  checklist to work from).
- `context/` - per-area context. Index: `context/README.md`. Area files:
  `architecture.md`, `technical-leadership.md`, `frontend-development.md`, `backend-development.md`,
  `quality-assurance.md`, `product-management.md`, `security.md`.
- `agents/` - role playbooks: `tech-lead.md`, `qa-automation.md`, `frontend-dev.md`, `backend-dev.md`.

Team coding rules for the JavaScript apps remain in `.cursor/rules/`.
